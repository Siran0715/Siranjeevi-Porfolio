EduVerse

AI-Integrated Student Management System

A student management application with authentication, an admin-style dashboard and an AI assistant, split into a Spring Boot backend and a React frontend.

The application covers student records with create, read, update and delete, user management, audit logs, a dashboard and a settings page. Login and registration use JWT authentication. The assistant screen sends questions to Google's Gemini API through the backend.

OrbitMeet

Real-Time Video Conferencing Web Application

Orbit Meet / Start screen

Rooms and presence

A meeting is a room. One person creates it, and others join with its ID, so the app has to track who is in which room at any moment.

WebRTC for media

WebRTC lets browsers send audio and video streams to each other. It is the technology behind the live video in this project.

WebSocket for messaging

A WebSocket keeps a two-way connection open between a browser and a server, which suits events that must arrive immediately.
